# Shop POS - Admin Management Console

This is the dedicated Admin management console for Shop POS.
It can be served automatically by the Backend Web Service at `/admin` (recommended), or run independently as a static dashboard.

---

## 🛠 Local Development
```bash
npm install
npm run dev
```
Open `http://localhost:5174` in your browser.

## 📦 Production Build
```bash
npm run build
```
The output will be placed in the `dist` folder.
